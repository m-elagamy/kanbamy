الهدف من هذا السجل هو توثيق الأسباب الجذرية للمشاكل (`Root Causes`) والأنماط المعمارية (`Architectural Patterns`) لتجنب تكرار الأخطاء وبناء مرجع هندسي دائم.

---

## 📋 The Template (قالب التدوين)

كل تدوينة تتبع هيكل بسيط ومباشر من 4 أقسام:

1. **The Context / Problem (المشكلة أو التساؤل):** ماذا كنا نحاول أن نفعل وما هو العرض الظاهر؟
2. **The Root Cause (السبب الجذري):** لماذا حدثت المشكلة في محرك الـ Framework أو الـ Architecture؟
3. **The Architectural Pattern (الحل المعماري):** ما هو النمط أو الـ Best Practice المطبق لحلها؟
4. **Exceptions & Rules of Thumb (القاعدة والاستثناءات):** متى نطبق هذه القاعدة ومتى يكون هناك استثناء؟
